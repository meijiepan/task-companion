# Task Companion 隐私说明 / Privacy Notice

更新日期 / Updated: 2026-11-09

## 中文

Task Companion 使用 ChatGPT Sites 登录识别账号。服务接收站点专属用户 ID，并保存你创建的项目和任务名称（中文及英文）、任务父子关系、排序、完成时间、当前选中任务及更新时间。服务不主动保存聊天全文，也不要求你提供 OpenAI API 密钥。托管及登录平台可能为了提供服务处理账号资料和使用记录；其处理方式以平台自己的政策为准。

当你在 ChatGPT 中调用插件工具时，工具所需的任务内容会经过 ChatGPT 和站点服务。请勿把不愿交给这两个平台处理的敏感资料写进任务。任务只按登录账号的站点专属用户 ID 查询；未登录的任务 API 会拒绝访问。我们没有内置公开分享任务的功能。

你可以在网页中导出 JSON，或删除自己在本服务的全部项目和任务。删除后无法从本服务恢复。若需帮助，请在 [GitHub Issues](https://github.com/meijiepan/task-companion/issues) 提交不含私人任务内容的问题。

## English

Task Companion uses ChatGPT Sites sign-in to identify accounts. It receives a site-scoped user ID and stores your project and task titles (Chinese and English), task hierarchy and order, completion timestamps, selected task, and update timestamps. The service does not intentionally store full chat transcripts or ask for an OpenAI API key. Hosting and sign-in providers may process account details and usage records under their own policies.

When you call plugin tools in ChatGPT, the task data needed for that call passes through ChatGPT and the Site service. Do not enter sensitive material you are unwilling to share with those platforms. Task queries are scoped to the signed-in site's user ID; anonymous task API requests are rejected. There is no built-in task-sharing feature.

You can export your data as JSON or delete all of your projects and tasks in the web app. Deleted data cannot be recovered from this service. For help, open a [GitHub Issue](https://github.com/meijiepan/task-companion/issues) without including private task content.
